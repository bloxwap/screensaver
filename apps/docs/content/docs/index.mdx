Choose **Bitcoin (BTC)**, **Solana (SOL)**, **Ethereum (ETH)**, or **Hyperliquid (HYPE)** on the [download page](/#downloads). Each edition follows its market with a live price, a full-screen chart, and a QR link to trade that asset on Bloxwap.

## Try it first

Select **Preview** beside an asset to run the display in your browser. No installation, account, or wallet is needed. Fresh prices require internet access.

- [Preview Bitcoin](/preview/?asset=BTC)
- [Preview Solana](/preview/?asset=SOL)
- [Preview Ethereum](/preview/?asset=ETH)
- [Preview Hyperliquid](/preview/?asset=HYPE)

Move the pointer or tap to reveal the controls. Choose fullscreen for an immersive view, or **Downloads** to return to the website. See [preview controls](/docs/preview).

## Install an edition

Choose **Mac**, **Windows**, or **Linux** in the asset's row. Mac download labels distinguish native **.saver** bundles from archived **App** releases, for Apple silicon or Intel. Windows and Linux downloads install desktop apps. Files come from public GitHub Releases; GitHub sign-in is not required.

The page identifies unsigned preview builds. Their operating-system prompts and support status differ from signed stable releases. Follow the [installation guide](/docs/installation) for your platform.

## Start it when idle

On Mac, install the `.saver` bundle and select it in macOS Screen Saver settings. macOS controls when it starts, its preview, and how it dismisses.

On Windows or Linux, open the app's **Settings** and turn on **Start when my computer is idle**. It starts disabled, and the app must remain running. Its tray menu lets you preview, reopen, or quit it.

Your computer's sleep and secure-lock settings still apply. [Desktop settings](/docs/settings) explains idle activation and connected displays.
