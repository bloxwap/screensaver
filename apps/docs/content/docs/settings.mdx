## Mac

After [installing the native bundle](/docs/installation), open **System Settings**, search for **Screen Saver**, and select your Bloxwap edition. Use the system preview and activation controls.

macOS owns the idle timer, preview host, connected-display placement, dismissal, sleep, and password/lock behavior. Set these through the operating system. The saver renders the selected market inside that host; it does not run a separate Bloxwap tray app or control the computer's lock policy.

The settings layout varies by macOS version. [Apple's Screen Saver guide](https://support.apple.com/guide/mac-help/mchlp1227/mac) describes the current controls.

## Windows and Linux

Open **Settings** in the installed app. Each asset edition keeps independent preferences.

### Automatic activation

Turn on **Start when my computer is idle**, then choose a wait time from 1–30 minutes. It starts disabled.

The app must be running. With idle activation enabled, closing its main window leaves it in the system tray. Startup at login is not enabled automatically.

The idle display opens on connected displays. Move the pointer or press a key to dismiss it and return to your desktop. Sleep, suspension, and secure-lock settings still apply.

These apps do not replace the secure lock screen. Windows uses a standalone display rather than a `.scr` module.

### Tray controls

- **Open** returns to the main display and its settings.
- **Preview screensaver** starts the fullscreen desktop preview.
- The idle-activation checkbox enables or disables automatic activation.
- **Quit** closes the app and stops automatic activation.

If no system tray is available, automatic activation stays unavailable. On Linux, the session must also expose idle state; some Wayland compositors do not.

## Multiple editions

Bitcoin, Solana, Ethereum, and Hyperliquid install separately. On Mac, select the edition you want in the system's Screen Saver settings. On Windows and Linux, enable automatic activation only for the desired edition so several apps do not open over one another.

Use [browser previews](/docs/preview) to compare editions without changing desktop settings.
