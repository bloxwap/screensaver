---
title: Installation
description: Install, update, or remove an edition on Mac, Windows, or Linux.
---

Choose an asset and operating system on the [download page](/#downloads). Every edition opens its selected asset automatically. You can install more than one edition.

## Mac

Choose **Apple silicon** for an M-series Mac or **Intel** for an Intel Mac. Find the processor in **Apple menu → About This Mac**. Follow the download's type label: **.saver** is the native `0.2.x` edition; **App** identifies an archived `0.1.x` desktop app.

### Native .saver downloads

The native build targets **macOS 13 Ventura or newer**. Check the [native host compatibility note](/docs/troubleshooting#macos-host-compatibility) for the versions and runtime behavior actually verified.

1. Download and open the edition's DMG, or extract its ZIP.
2. Copy the enclosed `.saver` bundle, such as **Bloxwap Bitcoin Screensaver.saver**, into `~/Library/Screen Savers` for your account. Finder's **Go → Go to Folder** can open that location; create the `Screen Savers` folder if needed.
3. To install for all users instead, copy the bundle into `/Library/Screen Savers`; administrator access may be required.
4. Open **System Settings**, search for **Screen Saver**, and select the installed Bloxwap edition. Use the system preview to check it.

macOS controls screen-saver activation, dismissal, locking, and connected-display behavior. A Bloxwap tray process does not need to stay running. The labels and location of the screen-saver controls vary across macOS versions; see [Apple's settings guide](https://support.apple.com/guide/mac-help/mchlp1227/mac).

Preview bundles may be unsigned or ad-hoc signed without a verified publisher identity, and macOS may block them. Check the release's signing status before installing. Use the [browser preview](/docs/preview) if you prefer to wait for a signed build. Stable Mac releases require native bundle signing, notarization, and verification.

If you installed an older `0.1.x` Mac app, quit it from its tray menu before using the native saver. You can then remove that old app from Applications. The `0.2.x` Mac download installs into the Screen Savers folder.

### Archived App downloads

For a download marked **App**, open its DMG or extract its ZIP, move the `.app` into **Applications**, and launch it there. Its own Settings and tray menu manage optional idle activation. It does not appear as a native edition in macOS Screen Saver settings. Quit it from its tray menu before updating or removing it from Applications.

## Windows

Download the **x64 installer**, open it, and follow its installation steps. Launch the edition from the Start menu or the shortcut created by the installer. Check the release notes for the Windows versions actually verified for that release.

Preview installers are unsigned and Windows may show an unknown-publisher or reputation prompt. The download page identifies their status. Signed releases can still receive reputation prompts; the [browser preview](/docs/preview) is available without installation.

Configure optional idle activation in the app's Settings. The app does not install a `.scr` entry into Windows' Screen Saver Settings.

## Linux

Choose the **x64 AppImage** for a portable app or **DEB** for a compatible Debian-based distribution. Check the release notes for tested distributions and desktop sessions.

For an AppImage, allow the downloaded file to run as a program in your file manager, then open it. From a terminal, replace the example filename with your download:

```sh
chmod +x ./bloxwap-screensaver.AppImage
./bloxwap-screensaver.AppImage
```

Open a DEB with your distribution's package installer, then launch the installed app. AppImage runtime dependencies and tray support vary. If an AppImage reports a missing FUSE library, follow your distribution's AppImage instructions or use the DEB where supported.

Idle detection depends on the desktop session. Some Wayland compositors do not expose system idle time, so automatic activation may be unavailable even when manual preview works.

## Updates and checksums

On Mac, select another screen saver and close System Settings before replacing the existing edition's `.saver` bundle in its installation folder. Reopen Screen Saver settings and select the updated edition.

On Windows and Linux, quit the edition from its tray menu before installing a newer version of the same edition. Download updates from the website or [GitHub Releases](https://github.com/bloxwap/screensaver/releases). Check the version, architecture, and release channel before replacing the installed edition.

Each release includes `SHA256SUMS` and `release-manifest.json`. The website's download metadata comes from that manifest. Editions do not automatically install updates.

## Uninstall

On Mac, select another screen saver, close System Settings, and remove the edition's `.saver` bundle from `~/Library/Screen Savers` or `/Library/Screen Savers`, wherever you installed it.

On Windows and Linux, quit the app first. Use **Settings → Apps** on Windows. On Linux, delete a portable AppImage or remove the installed DEB using your package manager. Stored preferences may remain after removal.

## Phones and tablets

Use a [browser preview](/docs/preview). Supported browsers can add it to the Home Screen. Mobile launches manually and does not replace the device's lock screen or system screensaver.
